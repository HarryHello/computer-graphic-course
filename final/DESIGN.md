# Inkshift 游戏设计

Inkshift 是一款单人 3D 平台跳跃游戏。玩家在浮空平台上切换立方体与球体，沿四条路线抵达终点。关卡由平台、梁和坡道组成，下面铺有云层。

## 操作与反馈

- **立方体**在平地上沿当前视角的四个方向翻滚，每步一条边长，从当前位置起步。松开方向键会完成当前一步。起跳可以打断翻滚，按住方向换镜头后，下一步沿新的视角方向移动。
- **球体**持续加速，可斜向行进。松开方向键后仍会滑行，反方向输入会更快减速。球体可以靠坡道的速度离地。落地前的切换会保留当前速度，在地面切回立方体则会制动。
- **跳跃**可在空中追加一次。短按和长按产生不同高度，离开边缘后有 0.11 秒起跳宽限，起跳输入保留 0.14 秒。参考了《蔚蓝》的跳跃容错做法。[开发者公开的角色控制代码](https://github.com/NoelFB/Celeste/blob/master/Source/Player/Player.cs)
- **镜头**从高处跟随角色。Q / E 每次转动 90°，输入按新朝向解读，球体已有的速度保留原方向。界面显示当前朝向和剩余跳跃次数。
- **颜料**随形态留下橙色方印或青色圆印，只画在探测到的地面上。落地、翻滚、形态切换、检查点和通关有各自的提示音。

## 关卡节奏

| 路线 | 布局与动作 |
| --- | --- |
| First Marks | 从宽平台进入窄梁，通过两次跨越练习立方体步幅和二段跳。 |
| Slipstream | 穿过下坡和谷底，在上坡末端凭球体速度飞跃长缺口。 |
| Quarter Turn | 在三个交叉方向上寻找落点，练习按住前进时改变视角方向。 |
| The Cloudline | 先过窄梁，再转向助跑飞跃，最后跳上逐级升高的三块平台。 |

蓝色箭头标方向，橙色箭头与横纹标示起跳区域，薄荷绿门架标示终点。越过检查点后，掉落或按 R 会回到该点，并恢复该处预设的形态与朝向。通关解锁下一关并记录最快用时，关卡可从标题页重玩。

浅色陶瓷表面、蓝色底座和青橙色角色用于区分地形、路线提示和颜料。当前使用 Unity URP 的平行光和软阴影，课程要求的自实现 Phong 光照和阴影将在后续替换。

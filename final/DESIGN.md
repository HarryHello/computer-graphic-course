# Inkshift 游戏设计

Inkshift 是一款单人 3D 平台跳跃游戏。四间封闭实验室各有一条测试路线。玩家在窄梁、错位踏板和坡道上切换立方体与球体，穿过卷帘门抵达终点。

## 操作与反馈

- **立方体**在平地上沿当前视角的四个方向翻滚，每步一条边长，从当前位置起步。半途按相反方向会沿原来的翻转轨迹退回起点，持续按住则接着向反方向翻滚。松开方向键会完成当前一步，侧向输入和镜头切换会在下一步生效。起跳可以打断翻滚。
- **球体**持续加速，可斜向行进。松开方向键后仍会滑行，反方向输入会更快减速。球体可以靠坡道的速度离地。落地前的切换会保留当前速度，在地面切回立方体则会制动。
- **跳跃**可在空中追加一次，角色会朝运动方向快速前翻一圈。短按和长按产生不同高度，离开边缘后有 0.11 秒起跳宽限，起跳输入保留 0.14 秒。参考了《蔚蓝》的跳跃容错做法。[开发者公开的角色控制代码](https://github.com/NoelFB/Celeste/blob/master/Source/Player/Player.cs)
- **镜头**从高处跟随角色。Q / E 每次转动 90°，输入按新朝向解读，球体已有的速度保留原方向。界面显示当前朝向和剩余跳跃次数。
- **颜料**在接触的平台和墙面上留下轨迹，立方体留下橙色湿漆，球体留下青色湿漆。表面分别记录两种颜料的厚度和湿度，轨迹相遇时按颜料量混色。落地会将颜料向外推开，湿漆会扩散，也会沿斜面流动、从板边垂落。厚度起伏影响漆面反光，薄处先变透明，轨迹随后消退。
- **角色外观**使用可折射背景的半透明凝胶材质。方块带圆角，移动时轻微形变，起跳时拉伸，落地时压扁回弹。动画只改变外观，碰撞体大小保持稳定。

## 关卡节奏

| 路线 | 布局与动作 |
| --- | --- |
| First Marks | 从宽平台进入计量窄梁，练习立方体步幅。接着跳过错位踏板，在两条横梁之间多次转向，最后用连续跳跃抵达出口。 |
| Slipstream | 第一次以球体穿过下坡、谷底和上坡，靠速度越过缺口。落地后切回立方体制动，过窄梁和短跳平台，再以球体从第二条坡道飞入出口走廊。两段坡道都可凭速度离地。 |
| Quarter Turn | 沿北、东、西、南四个朝向穿越窄梁和错位踏板，在交叉口跟随青色箭头切换镜头朝向。 |
| Transfer Wing | 先过窄梁并二段跳，再转向助跑，以球体越过坡道后的缺口。落地切回立方体制动，沿折返踏板转向，跳上三块逐级升高的平台。 |

青色箭头标示路线方向，琥珀色横纹标示助跑坡道的末端。每条路线有三个检查点。掉落或按 R 时，角色保留当前形态并回到最近激活的检查点或关卡起点。复活后，镜头正前方指向下一段主路线。

## 通关与切换

角色进入门前触发区后停止计时，镜头转向卷帘门。角色先滚到门前等候，钢制门帘升入门箱，再以当前形态滚入门内。结算显示用时、重试次数和新纪录提示，可继续下一关、重玩或返回标题。切换场景时先淡入黑场，再淡出到新场景。最后一关的继续按钮返回标题。

最快用时按路线存于本机。过往通关进度保留解锁资格，四条新版路线单独记录用时。

## 实验室与界面

实验室使用带磨损纹理的蓝灰墙板和浅色踏板。钢制桁架、支架与管架露在墙边和平台下方，冷白壁灯照亮行进面，琥珀色灯条标出出口。服务坑位于掉落判定线下方，铺有带积水贴图的地面和排水格栅。镜头转到墙外时，挡住视野的墙面和墙上的颜料一同隐藏，墙体仍会挡住角色。凝胶和湿漆使用室内反射贴图。当前光照和阴影由 Unity URP 渲染，课程要求中的自实现 Phong 光照和阴影将在后续完成。

标题展示两种凝胶形态，菜单和 HUD 沿用深灰面板及青色、琥珀色信号色。关卡界面显示当前形态、剩余跳跃、镜头朝向、检查点、用时和重试次数。按钮响应悬停和按下，形态、跳跃和检查点发生变化时，读数会短暂放大。

# Inkshift 游戏设计

Inkshift 是一款单人 3D 平台跳跃游戏。玩家在平台、梁和坡道上切换立方体与球体，沿四条路线抵达终点。第一关在封闭实验室内，其余路线悬在云层上方。

## 操作与反馈

- **立方体**在平地上沿当前视角的四个方向翻滚，每步一条边长，从当前位置起步。半途按相反方向会沿原来的翻转轨迹退回起点，持续按住则接着向反方向翻滚。松开方向键会完成当前一步，侧向输入和镜头切换会在下一步生效。起跳可以打断翻滚。
- **球体**持续加速，可斜向行进。松开方向键后仍会滑行，反方向输入会更快减速。球体可以靠坡道的速度离地。落地前的切换会保留当前速度，在地面切回立方体则会制动。
- **跳跃**可在空中追加一次，角色会朝运动方向快速前翻一圈。短按和长按产生不同高度，离开边缘后有 0.11 秒起跳宽限，起跳输入保留 0.14 秒。参考了《蔚蓝》的跳跃容错做法。[开发者公开的角色控制代码](https://github.com/NoelFB/Celeste/blob/master/Source/Player/Player.cs)
- **镜头**从高处跟随角色。Q / E 每次转动 90°，输入按新朝向解读，球体已有的速度保留原方向。界面显示当前朝向和剩余跳跃次数。
- **颜料**随形态留下橙色或青色湿漆。每块平台记录两种颜料的厚度和湿度，轨迹相遇时按颜料量混色。落地会将颜料向外推开，湿漆会扩散，也会沿坡面缓慢流动。厚度起伏决定漆面的高光。
- **角色外观**使用可折射背景的半透明凝胶材质。方块带圆角，移动时轻微形变，起跳时拉伸，落地时压扁回弹。动画只改变外观，碰撞体大小保持稳定。

## 关卡节奏

| 路线 | 布局与动作 |
| --- | --- |
| First Marks | 从宽平台进入窄梁，通过两次跨越练习立方体步幅和二段跳。 |
| Slipstream | 穿过下坡和谷底，在上坡末端凭球体速度飞跃长缺口。 |
| Quarter Turn | 在三个交叉方向上寻找落点，练习按住前进时改变视角方向。 |
| The Cloudline | 先过窄梁，再转向助跑飞跃，最后跳上逐级升高的三块平台。 |

蓝色箭头标方向，橙色箭头和横纹提示起跳。实验室的琥珀色卷帘门和浮空路线的薄荷绿门架分别标示终点。掉落或按 R 时保留角色当时的形态，回到最近的检查点或关卡起点。复活锚点的正前方指向主路线的下一段，按住前进即可继续。通关解锁下一关并记录最快用时，关卡可从标题页重玩。

实验室以蓝灰墙板、浅色踏板、冷白壁灯和琥珀色出口建立明暗层次。排水坑位于掉落判定线下方。镜头转到墙外时隐藏挡在镜头前的那面墙，室内光源继续照亮踏板、凝胶和湿漆。浮空路线使用浅色陶瓷、蓝色底座和体积云雾，云雾读取 URP 的主光阴影。课程要求的自实现 Phong 光照和阴影将在后续替换。

标题、菜单和 HUD 统一采用圆角，按钮响应悬停和按下，形态、跳跃和检查点的状态变化会短暂放大提示。
